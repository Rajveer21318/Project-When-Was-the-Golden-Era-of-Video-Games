# 🎮 Golden Age of Video Games – SQL Analysis

## 📌 Project Overview
The global gaming market is projected to exceed $300 billion by 2027. This project analyses sales and review data for over 400 video games released since 1977 to answer:
- Which are the best-selling games of all time?
- Which years received the highest ratings from critics and users?
- Is there a “golden age” of video games?

## 🗄️ Dataset
- **game_sales**: Game name, release year, and sales figures
- **reviews**: Critic and user scores
- Source: DataCamp / Kaggle (full dataset includes over 13,000 games)

## 🛠️ Tools & Skills Used
- **SQL**: `SELECT`, `JOIN`, `GROUP BY`, `HAVING`, aggregate functions, filtering, sorting
- Data extraction, aggregation, and insight generation
- Summarising and presenting findings to non-technical audiences

## 🔍 Key Queries & Insights
1. **Top 10 best-selling games** — ordered by copies sold
2. **Top-rated years** — average critic scores for years with at least 4 games reviewed
3. **Golden years** — years where average critic or user ratings exceeded 9, showing the gap between critic and user opinions
